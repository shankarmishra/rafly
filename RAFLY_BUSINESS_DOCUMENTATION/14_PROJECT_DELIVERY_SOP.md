## 1. STAGING DEMO & DEFINITION OF DONE (DOD)
Before presenting Staging Demo to client, the project MUST pass internal QA:
- [ ] Mobile & Desktop Responsiveness verified across Chrome, Safari, Firefox.
- [ ] Page speed score verified (< 1.5s load time).
- [ ] SSL certificate active and HTTPS enforced.
- [ ] Forms tested with test submissions reaching CRM/WhatsApp webhook.
- [ ] 0 Critical security vulnerabilities detected.
