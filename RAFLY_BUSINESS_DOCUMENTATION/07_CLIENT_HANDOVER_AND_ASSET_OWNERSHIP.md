## 1. OUR OWNERSHIP PHILOSOPHY

We believe your digital assets belong to you. RAFly guarantees that upon final payment of your invoice, complete control and ownership of your platform transfers to your business.

```
┌───────────────────────────────────────────────────────────────────────────┐
│                      ASSET OWNERSHIP GUARANTEE                            │
├───────────────────────────────────────────────────────────────────────────┤
│ ✅ Client Transferred Assets (Upon Final Payment):                        │
│    • 100% Bespoke Source Code, HTML, CSS, JavaScript, and PHP scripts.   │
│    • Domain registration accounts, DNS control, and hosting credentials.  │
│    • Database dumps, media assets, graphics, and written content.         │
│    • Ad accounts (Meta Ads Manager, Google Ads), Pixel, and Analytics.    │
│                                                                           │
│ ⚠️ Excluded / Proprietary Assets:                                         │
│    • RAFly internal framework tools, pre-existing code libraries.        │
│    • Commercial third-party plugin licenses (Client must hold license).   │
└───────────────────────────────────────────────────────────────────────────┘
```

At project closure, RAFly provides a master Handover Package containing:
1. **Master Credential Matrix:** Secure vault link with administrative access to server, database, DNS, and CMS.
2. **Source Code Repository:** Full git repository zip / access link.
3. **Database Backup:** Sanitized SQL export of your production database.
4. **Documentation:** 1-page system architecture summary and administrative user guide.
