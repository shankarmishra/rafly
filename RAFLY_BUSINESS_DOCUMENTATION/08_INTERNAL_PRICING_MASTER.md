## 1. INTERNAL PRICING FORMULA

All project quotes are calculated using RAFly's cost-plus & complexity estimation model:

$$\text{Project Price} = (\text{Base Scope Hours} \times \text{Hourly Rate}) \times \text{Complexity Multiplier} + \text{Urgency Premium} + \text{Third-Party Costs}$$

### Key Internal Parameters:
- **Standard Internal Rate:** ₹1,500 – ₹2,500 / hour ($30 – $50 / hour for international clients).
- **Minimum Project Floor:** ₹20,000 for local custom web projects (never accept sub-₹15k deals).
- **Urgency Premium (24-48 hr turnaround):** +50% surcharge on total labor hours.
- **Complexity Multipliers:**
  - Standard PHP / HTML / CSS: 1.0x
  - Custom E-commerce / Payment API Integration: 1.2x
  - Complex API / Legacy Refactoring: 1.4x
