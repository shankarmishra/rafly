## Libraries

**None.** The site has zero third-party JavaScript. All behaviour is hand-
written and dependency-free: `js/app.js`, `js/motion.js` (reveals, counters,
tilt, the scroll-progress values `--p` / `--hp` that drive the services ring
and the hero handshake), `js/scroll.js`, `js/gl.js` (WebGL2 point-cloud
renderer — the delivery-flow object), `js/smooth.js` (inertial wheel
scrolling).

> **Technique references, not vendored code.** Open-source projects studied
> for *how* an effect is built and then re-implemented here from scratch:
> [Lenis](https://github.com/darkroomengineering/lenis) (MIT) for the
> smooth-scroll integration rules in `js/smooth.js`; [Aceternity
> UI](https://ui.aceternity.com) (free components, MIT) and [Magic
> UI](https://github.com/magicuidesign/magicui) (MIT) for the component
> effects in `css/13-fx.css` (gradient border, border beam, lamp, highlight,
> moving border, shiny text, pointer spotlight); the classic CSS 3-D carousel
> (David DeSandro's *Intro to CSS 3D transforms*) for the services ring in
> `css/pages/home.css`. Ordered (Bayer) dithering, the treatment every image on
> the site is printed with, is public-domain mathematics implemented in
> `inc/tools/build-paper.php`. No source from any of these ships; nothing is
> loaded from a CDN.

## Generated brand assets

`logo.png` in the project root is the **master artwork** (1408x736, 176 KB) and
is no longer served to visitors. Everything in `assets/` below is derived from
it by cropping and resampling — no redrawing, no tracing, so these are the real
mark rather than an approximation. Regenerate them from the master if the logo
is ever updated.

| File | Size | Used by |
|---|---|---|
| `logo.png` | 320x99, 21 KB | header (120x37) and footer (100x31) |
| `og-cover.png` | 1200x630, 64 KB | `og:image` / `twitter:image` |
| `apple-touch-icon.png` | 180x180, 12 KB | iOS home screen (opaque white — iOS composites transparency on black) |
| `favicon-32.png` | 32x32, 1.4 KB | SVG-favicon fallback |
| `icon-192.png` / `icon-512.png` | 11 KB / 50 KB | PWA manifest, and `Organization.logo` in JSON-LD |

Two constraints drove the formats: no social-share crawler accepts SVG for
`og:image`, and iOS ignores an SVG `apple-touch-icon` — so those had to be PNG
regardless of preference. The 512 is also what JSON-LD points at, because Google
rejects an `Organization.logo` under 112px on either axis and the horizontal
lockup is only 99px tall.

The header logo went from 176 KB to 21 KB, and `og:image:width/height` (1200x630)
are now true instead of describing a 1408x736 image.
