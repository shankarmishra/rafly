## Intent Classification Rules
1. **Commercial / Transactional (`/web-development`, `/web-security`, `/marketing-advertisement`, `/content-creation`, `/ecommerce-support`)**: Targets users actively seeking an engineering partner or service quote.
2. **Local Commercial (`/locations/greater-noida`)**: Targets regional businesses in Greater Noida, Noida, and Delhi NCR seeking local technical collaboration.
3. **Comparison / Pricing (`/pricing`)**: Targets prospects evaluating scope boundaries, package tiers, and investment estimates.
4. **Informational / Authority (`/blog`, `/blog-post`)**: Targets users researching technical challenges, security vulnerabilities, or SEO strategies.
